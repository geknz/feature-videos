# Девайс серии — точная рамка из Netflix-видео

Это **кастомный фронтальный CSS-мокап с Dynamic Island**, а не проверенная модель iPhone. Не подменять его iPhone 15/16/17 из библиотеки: их размеры и рамка могут отличаться. Название пресета: `netflix-movie-device-v1`.

Применять во всех мобильных видео серии. Геометрия фиксирована. Меняется UI внутри, а не устройство.

## Геометрия до масштабирования

Все значения ниже — CSS px **до camera scale**, box-sizing: border-box.

| Параметр | Точное значение |
|---|---|
| Размер контейнера устройства / UI | 390 × 844 |
| Радиус всех углов | **48** |
| Padding, margin, border | 0 |
| Отдельная толщина bezel | Нет: UI доходит до края клипа |
| Фон самой рамки | Transparent, виден фон UI |
| Клип UI, островка, внутренних оверлеев | overflow: hidden |
| Контур | box-shadow `0 0 0 1px #ffffff38` |
| Тень | box-shadow `0 30px 70px #0009` |
| Transform origin | 50% 50%, локальный центр (195, 422) |
| Наклон / перспектива / вращение | Отсутствуют |
| Скролл контента | Внутри `.feature-video-screen`, scrollbar скрыт |

`#ffffff38` — белый с alpha 56/255, ~21.96%; `#0009` — чёрный с alpha 0.6. Контур — shadow, не border: он не отнимает пиксели у viewport. Не добавлять второй корпус, стекло, металлическую фаску, боковые кнопки или рамку в несколько пикселей.

В исходных CSS встречаются 36 и 38 px, но их переопределяет **48 px** в movie.css. Значения из обычного preview (`height:min(...)`, тень 24 px, outline #ffffff30) тоже переопределены для видео и не являются эталоном.

## Dynamic Island

Псевдоэлемент `device::after`, поверх контента:

- Размер **112 × 30**.
- `top:12px; left:50%; transform:translateX(-50%)` → локальный left **139 px**.
- `border-radius:30px; background:#000`.
- `z-index:500; pointer-events:none`.
- Без линзы камеры, блика, бордера и анимации островка.

Dynamic Island не вырезает отдельную область из viewport; статус-бар и контент должны учитывать его положение. Не добавлять safe-area-padding второй раз.

## Статус-бар и нижний индикатор

Статус-бар обновлён 30 октября 2026 по запросу пользователя; геометрия корпуса сохранена:

- Время **9:41**, фиксированное, системный Apple-шрифт (`-apple-system`, затем BlinkMacSystemFont / SF Pro Text / Helvetica Neue).
- Высота **54 px**, padding **4px 28px 0 32px**, flex space-between / align-items:center. Центр элементов по вертикали — 29 px.
- **17 px / 600**, line-height **22 px**, letter-spacing **−0.4 px**, tabular-nums, белый #fff.
- Справа signal, Wi-Fi, battery; промежуток **6 px**.
- Signal: **18 × 12**, Wi-Fi: **17 × 12**, battery: **27 × 13**; SVG viewBox соответствует размеру каждой иконки.
- Залитые силуэты вместо универсальных контурных иконок. У батареи контур и контакт с opacity **0.4**, внутренний заряд белый. Точные формы — в [`device-frame.html`](../assets/device-frame.html).
- Это визуальное приближение к iOS, не официальный аппаратный пресет. Существующие экспортированные ролики обновляются отдельным рендером.

Home indicator: **120 × 4 px**, белый #fff, radius **4 px**, `bottom:5px; left:50%; translateX(-50%)`. В оригинале он вложен в нижнюю навигацию, а не закреплён поверх любых панелей. Не дублировать его поверх drawer. Нижняя навигация — UI продукта, её иконки и оформление не входят в рамку серии.

Для светлого интерфейса фиксированный белый статус-бар требует контрастной подложки в самом продукте; не менять геометрию рамки ради этого. Изменение цвета системного chrome — отдельное явное исключение, а не случайное наследование стилей нового продукта.

## Положение устройства в кадре

| | 4:5 Netflix master | 9:16 Netflix story |
|---|---|---|
| Размер stage | 1080 × 1350 | 1080 × 1920 |
| CSS left / top до scale | 345 / 253 | 345 / 538 |
| Центр устройства в stage | (540, 675) | (540, 960) |
| Scale общего плана | **1.28** | **1.7** |
| Видимый размер без shadow | 499.2 × 1080.32 | 663 × 1434.8 |
| Видимый left / top | 290.4 / 134.84 | 208.5 / 242.6 |
| Радиус в итоговом кадре | 61.44 | 81.6 |

Не округлять 499.2 до 500 через изменение CSS width и не масштабировать контент отдельно от рамки. Вся рамка, островок, status bar, контур и тень масштабируются **одним transform**.

Отрисовка — deviceScaleFactor 2, затем уменьшение в целевой размер. 2× — плотность рендера, не ещё один CSS scale.

## Камера: позы Netflix и новый linear

В Netflix крупные планы использовали абсолютные scale **2.35** (toast) и **2.4** (Claim). Координаты итогового translateY: **−547.55** и **−703.2** соответственно; translateX = 0. Общий план translateX = translateY = 0. Эти позиции относятся к расположению кнопок Netflix; у другого продукта выбирается своя цель.

Сохранять точную общую позу и оболочку. Для камеры нового продукта использовать [`motion.mjs`](../assets/motion.mjs): напрямую интерполировать итоговые x/y/scale за 600 ms с linear. Не копировать spring/cubic-bezier из старых render.mjs/render-story.mjs. Пример позы первого Netflix close-up: `{x:0,y:-547.55,scale:2.35}`.

Стартовый диапазон абсолютного close-up scale 2.35–2.4 воспроизводит крупность Netflix. Он равен ~1.84–1.88× от общего плана 4:5, но только ~1.38–1.41× от общего плана 9:16. Не умножать story scale 1.7 ещё на универсальные 1.8: это даст другой, слишком крупный кадр.

## Использование другим агентом

1. Скопировать [`device-frame.css`](../assets/device-frame.css) и оболочку из [`device-frame.html`](../assets/device-frame.html), сохранив значения. Подключить CSS после глобального reset/стилей продукта.
2. Разместить UI нового продукта внутри 390×844. Статус-бар и home indicator должны существовать в одном экземпляре.
3. Клиповать модалки внутри устройства. Не портировать их в наружный document.body без адаптации контейнера.
4. Установить `data-format="4:5"` или `"9:16"`. Stage должен иметь фиксированный размер; уменьшение для удобного просмотра делать на внешней обёртке, не на самом capture-stage.
5. Камерой управлять на `.feature-video-device`. Начальное значение из CSS затем может быть заменено inline transform из timeline.
6. Сравнить открывающий общий план с [`netflix-device-reference.jpg`](../assets/netflix-device-reference.jpg): размер и центр устройства, углы, тонкость контура, островок и тень.

Готовый CSS относится только к рамке, не меняет глобальный body, фон видео, шрифт нового продукта или его дизайн. Фон Netflix movie-background.png и edge-fade — постановочная сцена, не материал корпуса; не запекать их в device.
